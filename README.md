# Node.js MySQL CRUD Application

A CRUD (Create, Read, Update, Delete) application developed using Node.js and MySQL.

---

## Description

This project demonstrates database operations using Node.js and MySQL.  
It supports Create, Read, Update, and Delete operations via REST APIs.
